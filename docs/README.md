## Convention d'ajout d'un document

1. Placer le fichier dans `docs/` (ou `docs/frontend/` pour un sujet spécifique au frontend) en `kebab-case.md`.
2. Renseigner en tête de document : titre, date, responsable et périmètre.
3. Ajouter une entrée dans le tableau d'index ci-dessus (nom du fichier, langue FR/EN, date, responsable, courte description).
